Abstract

The Full-Stack Developer Internship is a practical learning program completed as part of my internship at Gram Panchayat Waregaon, focusing on the design, development, and deployment of a Smart Complaint Management System for civic administration. The main objective of the internship is to apply full-stack web development concepts and tools to build a real-world application that improves communication between citizens and the Gram Panchayat.

The internship provides practical exposure to different layers of modern web application development. React 18 with Vite and Tailwind CSS is used for building a responsive, component-based frontend. Chart.js is used for data visualisation on the admin dashboard. Java 17 with Spring Boot 3.2, Spring Security, and JWT authentication form the backend REST API layer. PostgreSQL is used as the production relational database, while H2 is used during development. Deployment is managed via Docker Compose and Render.

The system supports three roles: Citizen, who can register, submit complaints with GPS coordinates, track status, and submit feedback; Worker, who can view assigned complaints and mark them resolved; and Admin, who manages complaint assignments, monitors SLA deadlines, and views audit logs and analytics dashboards.

During the internship, challenges such as implementing role-based JWT authentication, designing RESTful API endpoints, managing relational data models with complaint timelines and audit logs, handling SLA deadline tracking, and deploying a containerised full-stack application were addressed.

Overall, the internship provided practical experience in the full-stack development lifecycle and strengthened my understanding of React, Spring Boot, REST APIs, JWT security, PostgreSQL, Docker, CI/CD via Render, relational database design, component-based UI development, and analytical dashboard creation.

About the Organisation

Gram Panchayat Waregaon is a local self-government institution serving the rural village of Waregaon under the Phulambri Taluka, Sambhajinagar District, Maharashtra. As a constitutional body under the 73rd Amendment of the Indian Constitution, the Gram Panchayat is responsible for administering civic amenities, public infrastructure, sanitation, water supply, and welfare schemes for the village community.

The organisation sought to modernise its complaint-handling process by replacing a manual, paper-based system with a digital platform that allows citizens to register civic complaints online, enables transparent tracking of complaint progress, and provides administrators with tools to efficiently assign and monitor resolution by field workers.

Project Title

Smart Complaint Management System – Gram Panchayat Waregaon

Project Overview

The Smart Complaint Management System is a full-stack web application developed to help Gram Panchayat Waregaon manage civic complaints efficiently. Citizens can submit complaints with a title, description, category, priority level, and GPS coordinates, and track their complaint using a unique system-generated ID (WGR-YYYY-NNNNNN). Workers can view and resolve their assigned complaints. Admins can manage all complaints, assign workers, monitor SLA deadlines, and view analytics dashboards with Chart.js bar and doughnut charts.

Problem Statement

Gram Panchayat Waregaon previously managed civic complaints using a manual, paper-based process. Citizens had no transparent way to track complaints, administrators had no efficient tool to assign and monitor tasks, and there was no audit trail for accountability. This led to delays, missed complaints, and poor citizen satisfaction. The objective is to digitalise the complete complaint lifecycle with role-based access, transparent status tracking, SLA-based deadline monitoring, and a complete audit trail.

Challenges and Solutions
Challenge 1: Role-Based JWT Authentication

Implementing a secure authentication mechanism supporting three distinct roles (Citizen, Admin, Worker) with different access permissions across all API endpoints was a significant challenge.

Solution: Spring Security was configured with a custom JWT filter that intercepts every request, validates the token, and populates the security context with the user's role. Role-specific endpoint access was enforced using Spring Security's method-level security annotations.

Challenge 2: SLA Deadline Tracking and Overdue Detection

Automatically computing deadline timestamps based on complaint priority and flagging overdue complaints for the admin dashboard required careful date-time handling.

Solution: SLA deadlines are computed at complaint creation time by adding the priority-specific duration to the creation timestamp. Overdue detection is performed by comparing the current timestamp against the stored deadline during admin dashboard queries.

Challenge 3: Maintaining a Complete Audit Trail

Every status change, assignment, and feedback event had to be logged for accountability, while also building a separate citizen-facing timeline per complaint.

Solution: Two parallel mechanisms were implemented — complaint_updates for the citizen-facing timeline and audit_logs for the admin-facing accountability log. Both are updated within the same service transaction to ensure consistency.

Challenge 4: Docker and Render Deployment

Containerising a multi-service application (frontend, backend, database) and deploying it to a cloud platform while managing environment-specific configuration was challenging.

Solution: A docker-compose.yml file orchestrates all three services locally. For Render, the frontend is deployed as a Static Site and the backend as a Web Service, with a managed Render PostgreSQL database and environment variables managed via Render's dashboard.
